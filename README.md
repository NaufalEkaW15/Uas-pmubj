# Sistem Pengaduan Fasilitas Kampus

Aplikasi web berbasis CodeIgniter 4 yang dirancang untuk memudahkan mahasiswa dalam melaporkan kerusakan atau kekurangan fasilitas di dalam lingkungan kampus.

## Fitur Utama
* Mahasiswa dapat membuat laporan pengaduan fasilitas beserta deskripsi detailnya.
* Pemantauan status tindak lanjut pengaduan.
* Antarmuka web yang sederhana dan responsif.

## 🛠️ Teknologi yang Digunakan
* Bahasa: PHP
* Database: MySQL
* Web Server:XAMPP
